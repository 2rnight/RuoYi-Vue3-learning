# RuoYi-Vue3 前端系统课程大纲

> 面向对象：有一定 JavaScript 基础、希望系统掌握若依前端（Vue 3 + Element Plus + Vite）并能独立做业务开发的学习者。
> 课程规模：**10 个章节（第 0–9 章），共 41 课时**，每课时约 90 分钟（讲解 + 代码阅读 + 动手实践）。
> 建议节奏：每周 4 课时，约 10–11 周完成；也可以按章节拆分为"工程基础 → 业务开发 → 高级专题"三个阶段。
> 学习材料：本仓库源码、《学习建议》文档（`docs/学习建议.md`）、配套后端 RuoYi-Vue。

## 第 0 章 课程导学与环境准备（2 课时）

### 第 1 课：项目概览与技术栈
- **学习目标**：说清楚若依前端的定位、版本演进和技术栈构成。
- **知识点**：
  - 若依前后端分离架构；RuoYi-Vue2 / Vue3 / Vue3-TypeScript 版本对比（README）。
  - `package.json` 中的依赖分类：运行时依赖与开发依赖；`overrides` / `resolutions` 的作用。
  - 项目目录结构总览：`src/api`、`src/views`、`src/store`、`src/router`、`src/plugins` 等职责划分。
- **阅读材料**：`README.md`、`package.json`、`src/` 目录树。
- **实践任务**：绘制一张"目录 → 职责"的思维导图（或表格）。

### 第 2 课：环境搭建与首次运行
- **学习目标**：完成前后端联调，成功登录系统并访问首页。
- **知识点**：
  - Node.js / 包管理器（yarn、npm）；`yarn dev`、`yarn build:prod`、`yarn build:stage`、`yarn preview`。
  - 后端 RuoYi-Vue 启动（8080 端口）；开发代理 `/dev-api → localhost:8080`。
  - 默认账号 `admin / admin123`；浏览器 Network 面板观察请求与 `Authorization` 头。
- **实践任务**：把"登录请求"的完整 URL、请求头、响应体截图记录下来，并标注每个字段的来源。

## 第 1 章 工程化基础：Vite（4 课时）

### 第 3 课：应用启动流程与环境变量
- **学习目标**：能描述从 `index.html` 到页面渲染的完整启动链路。
- **知识点**：
  - `index.html` → `src/main.js` 的入口关系；`createApp`、`app.use`、`app.mount` 的顺序。
  - `.env.development` / `.env.staging` / `.env.production`；`VITE_` 前缀规则；`import.meta.env` 的使用。
  - `mode` 与 `loadEnv`，以及 `VITE_APP_BASE_API` 如何影响请求地址。
- **实践任务**：新增一个环境变量 `VITE_APP_DEMO_FLAG`，在页面中读取并显示；体会"修改 .env 需重启"。

### 第 4 课：Vite 配置详解
- **学习目标**：能读懂并修改 `vite.config.js` 的关键配置。
- **知识点**：
  - `resolve.alias`：`@` 与 `~` 别名；`resolve.extensions`。
  - `server`：端口、`host: true`、`open`、`proxy` 的 `rewrite`；springdoc 接口代理 `^/v3/api-docs/(.*)`。
  - `build`：`outDir`、`sourcemap` 的开发/构建差异、`chunkSizeWarningLimit`、`rollupOptions.output` 文件命名规则。
  - `css.postcss`：自定义插件移除 `@charset`。
- **实践任务**：把开发代理目标改为其它端口，验证接口是否仍能访问，并恢复。

### 第 5 课：Vite 插件体系
- **学习目标**：理解插件如何按需接入，并能说出每个插件解决的问题。
- **知识点**：
  - `vite/plugins/index.js` 的组装逻辑；开发与构建的差异化插件（`isBuild`）。
  - `unplugin-auto-import`：自动导入 Vue、Pinia、Vue Router 的 API，以及 `.eslintrc`/类型声明的生成位置。
  - `unplugin-vue-setup-extend-plus`：`<script setup name="...">` 写法。
  - `vite-plugin-svg-icons`：SVG 雪碧图与 `virtual:svg-icons-register`。
  - `vite-plugin-compression`：生产 gzip 产物。
- **实践任务**：在一个组件中去掉 `ref` 的手动导入，验证自动导入生效；给一个组件加上 `name`，观察 `keep-alive` 中的表现。

### 第 6 课：构建脚本、部署与兼容
- **学习目标**：能完成一次生产构建并理解部署相关配置。
- **知识点**：
  - `build:prod` 与 `build:stage` 的区别；`dist/` 产物结构（`static/js`、`static/css`）。
  - `base` 配置与子路径部署；`vite preview` 本地验证。
  - Windows 打包脚本 `bin/build.bat`、`bin/package.bat`、`bin/run-web.bat` 的执行逻辑。
  - `html/ie.html` 的兼容提示页面，以及现代浏览器的兼容边界。
- **实践任务**：执行 `yarn build:prod`，统计产物体积，尝试用 `vite preview` 访问并确认路由刷新正常。

## 第 2 章 Vue 3 核心与 Element Plus（5 课时）

### 第 7 课：组合式 API 与 `<script setup>`
- **学习目标**：熟练使用 `ref`、`reactive`、`computed`、`watch`、`watchEffect`。
- **知识点**：
  - `<script setup>` 的语法糖：顶层变量直接暴露给模板，`defineProps`、`defineEmits`。
  - 响应式基础：`ref` 的 `.value`、`reactive` 的解构陷阱、`toRefs`。
  - 项目中的典型用法：`src/views/system/user/index.vue` 中的 `queryParams`、`form`、`rules`。
- **实践任务**：把某个页面的 `reactive` 查询参数改写为 `ref`+`toRefs` 方式，并比较差异。

### 第 8 课：组件通信与插槽
- **学习目标**：掌握父子通信、跨层级通信和插槽的使用场景。
- **知识点**：
  - `props` 单向数据流；`emit` 事件；`v-model` 与 `modelValue` 约定。
  - 插槽：具名插槽、作用域插槽（如表格列自定义内容、`DictTag` 的使用场景）。
  - `provide` / `inject` 的跨层级通信；`ParentView` 的透传作用。
  - 组件目录组织：`src/components/*` 的 `index.vue` 约定。
- **实践任务**：封装一个带 `v-model` 的"状态切换"组件，并在用户列表中使用。

### 第 9 课：生命周期与 keep-alive 缓存
- **学习目标**：理解组件生命周期对页面缓存、数据加载的影响。
- **知识点**：
  - `onMounted`、`onUnmounted`、`nextTick` 的典型使用时机。
  - `<keep-alive>` 的 `include` 逻辑与 `name` 的关系；`meta.noCache` 的作用。
  - `watch` 监听路由参数变化时重新加载数据（如 `/system/user-auth/role/:userId`）。
- **实践任务**：在某个页面的 `onMounted` 中打印日志，切换标签页观察缓存与重新加载行为。

### 第 10 课：全局注册、自定义指令与插件
- **学习目标**：理解全局挂载的收益与代价，能编写自定义指令。
- **知识点**：
  - `main.js` 中的 `globalProperties` 与 `app.component` 全局注册。
  - `src/directive/index.js` 统一注册指令；`common/copyText.js` 的剪贴板指令实现。
  - `src/plugins/index.js` 的插件安装方式（`app.use(plugins)`）。
- **实践任务**：实现一个 `v-focus` 指令，并在搜索框中使用。

### 第 11 课：Element Plus 实战与主题
- **学习目标**：能使用表单、表格、弹窗、日期选择等常用组件完成页面。
- **知识点**：
  - `el-form` 的 `model`、`rules`、`ref` 校验流程；`el-table` 的列与操作列。
  - `el-dialog` 与 `el-date-picker` 的 `daterange` 与 `value-format`。
  - 全局尺寸配置（`Cookies.get('size')`）、中文语言包 `zh-cn`。
  - 暗黑模式：`element-plus/theme-chalk/dark/css-vars.css` 与样式变量 `src/assets/styles/`。
- **实践任务**：做一个"带校验的表单弹窗"，包含必填、长度、手机号格式校验。

## 第 3 章 状态管理：Pinia（3 课时）

### 第 12 课：Pinia 基础
- **学习目标**：能用 `defineStore` 定义和使用 store。
- **知识点**：
  - 选项式与组合式两种 store 写法；`state` / `getters` / `actions`。
  - `src/store/index.js` 统一创建 Pinia 实例；在组件与路由守卫中调用 store 的时机。
  - 持久化思路：`src/plugins/cache.js` 与 localStorage / sessionStorage 的封装。
- **实践任务**：新建一个 `demo` store，实现计数与持久化。

### 第 13 课：核心 store 解读
- **学习目标**：能说明每个核心 store 的职责与数据流。
- **知识点**：
  - `user.js`：`login`、`getInfo`（含默认密码修改、密码过期判断）、`logOut`。
  - `app.js`：侧边栏开合、设备类型、组件尺寸 `setSize`。
  - `settings.js`：`changeSetting`、`setTitle`、`toggleTheme`。
  - `dict.js`：字典缓存的 `getDict` / `setDict` / `cleanDict` / `initDict`。
  - `lock.js`：锁屏 `lockScreen` / `unlockScreen` 与路由联动。
- **实践任务**：画出"登录 → 获取用户信息 → 生成菜单 → 退出"各阶段 store 状态变化的时序图。

### 第 14 课：标签页（tagsView）状态管理
- **学习目标**：理解多标签页的数据结构与关闭策略。
- **知识点**：
  - `visitedViews`、`cachedViews`、`iframeViews` 三类数据的区别。
  - `addView`、`delView`、`delOthersViews`、`delAllViews`、`delLeftTags`、`delRightTags` 等操作。
  - `affix` 固定标签、`loadPersistedViews` 持久化（`tagsViewPersist` 配置）。
- **实践任务**：在设置中开启/关闭 `tagsViewPersist`，验证刷新后标签页是否保留。

## 第 4 章 路由与权限（5 课时）

### 第 15 课：Vue Router 4 基础与路由配置
- **学习目标**：能读懂并编写本项目的路由配置项。
- **知识点**：
  - `createWebHistory`；`constantRoutes` 与 `dynamicRoutes` 的区别。
  - 路由元信息字段：`hidden`、`alwaysShow`、`redirect: 'noRedirect'`、`name`、`meta.title/icon/breadcrumb/activeMenu/noCache`。
  - 动态路由参数与正则约束：`:userId(\d+)`、`:activeTab?` 可选参数。
  - 嵌套路由与 `Layout` 作为父级容器。
- **实践任务**：新增一个带 `:id(\d+)` 参数的详情页路由，并在页面中读取 `route.params`。

### 第 16 课：路由守卫与登录流程
- **学习目标**：逐行解读 `src/permission.js` 并能说明每个分支的意义。
- **知识点**：
  - `router.beforeEach` 的返回值语义（`true`、路径对象、字符串）。
  - 白名单 `whiteList` 与 `isPathMatch`；`redirect` 参数回跳。
  - 锁屏状态下的路由拦截；`isRelogin` 与登录过期提示。
  - `afterEach` 与 NProgress 进度条。
- **实践任务**：把 `/register` 从白名单中移除，验证未登录访问的跳转效果，并恢复。

### 第 17 课：动态路由生成
- **学习目标**：掌握"后端菜单 → 前端路由"的完整转换过程。
- **知识点**：
  - `getRouters` 接口与返回结构（`component`、`path`、`children`、`meta`）。
  - `filterAsyncRouter`、`filterChildren` 的递归处理；`Layout`、`ParentView`、`InnerLink` 特殊组件。
  - `loadView` 与 `import.meta.glob('./../../views/**/*.vue')`：字符串组件名到组件的映射。
  - `router.addRoute` 与 `replace` 重新导航；为什么要深拷贝响应数据。
- **实践任务**：在后端菜单（或 mock 数据）中新增一条菜单，手动走一遍转换流程并记录每一步的数据形态。

### 第 18 课：权限控制（按钮、角色与菜单）
- **学习目标**：能在页面中正确地做按钮级与角色级权限控制。
- **知识点**：
  - `plugins/auth.js`：`hasPermi`、`hasPermiOr`、`hasPermiAnd`、`hasRole`、`hasRoleOr`、`hasRoleAnd`。
  - 指令 `v-hasPermi`、`v-hasRole` 的 DOM 移除机制；`*:*:*` 与 `admin` 超级权限。
  - `utils/permission.js` 的 `checkPermi`、`checkRole`，以及 `filterDynamicRoutes` 对路由的过滤。
  - 权限标识命名规范：`模块:子模块:动作`。
- **实践任务**：为一个页面的三个按钮分别设置不同权限标识，用不同角色账号验证显示效果。

### 第 19 课：页面导航、标签页操作与外部页面
- **学习目标**：掌握程序化导航与标签页相关工具，并能集成外部页面。
- **知识点**：
  - `plugins/tab.js`：`openPage`、`closePage`、`refreshPage`、`updatePage`、`closeAllPage` 等。
  - 动态标题 `utils/dynamicTitle.js` 与 `settings.setTitle`。
  - 外链与内嵌页：`layout/components/InnerLink`、`components/iFrame`、`IframeToggle`。
  - `utils/validate.js` 中的 `isHttp`、`isExternal`、`isPathMatch`。
- **实践任务**：实现一个按钮，点击后用 `openPage` 打开一个新的标签页并显示自定义标题。

## 第 5 章 网络请求与数据交互（4 课时）

### 第 20 课：Axios 封装基础
- **学习目标**：理解 `request` 实例的创建与公共配置。
- **知识点**：
  - `axios.create`：`baseURL`（取自 `VITE_APP_BASE_API`）、`timeout`。
  - 默认请求头 `Content-Type: application/json;charset=utf-8`。
  - `src/api` 的组织方式：按业务模块分目录，每个函数返回 `request(...)` 的 Promise。
- **实践任务**：新建一个 `src/api/demo.js`，封装一个 GET 与一个 POST 接口。

### 第 21 课：拦截器详解
- **学习目标**：能解释请求与响应拦截器的每一步逻辑。
- **知识点**：
  - 请求拦截器：Token 注入、`isToken: false` 跳过、GET 的 `params` 序列化（`tansParams`）。
  - 防重复提交：`repeatSubmit: false`、`interval`、sessionStorage 中的 `sessionObj`、5MB 限制。
  - 响应拦截器：统一 `code` 处理（200、401、500、601、其它）；`errorCode.js` 错误码映射。
  - 网络层错误的友好提示（"后端接口连接异常""系统接口请求超时"）。
- **实践任务**：把一次提交的 `interval` 改为 3 秒，连续点击观察拦截效果。

### 第 22 课：接口模块化与错误码
- **学习目标**：能按规范设计和维护接口层代码。
- **知识点**：
  - 路径参数处理：`parseStrEmpty`；查询参数与请求体的区别。
  - 字典接口 `api/system/dict/data.js`、`type.js` 的分层组织。
  - 登录接口与 `isToken: false`、验证码接口的配合。
  - 接口与页面解耦的好处：页面只关心数据，不关心 URL。
- **实践任务**：为一个模块整理出完整的接口清单（增删改查、导出、状态修改），并统一放入 `src/api`。

### 第 23 课：文件上传与下载
- **学习目标**：掌握文件类接口的前端处理方式。
- **知识点**：
  - `plugins/download.js`：`name`、`resource`、`zip`、`saveAs`、`printErrMsg`。
  - `utils/request.js` 中的 `download` 方法：`responseType: 'blob'`、`blobValidate` 判断错误响应。
  - 上传组件：`FileUpload`、`ImageUpload`、`ImagePreview`；`ExcelImportDialog` 的导入流程。
- **实践任务**：在某个列表页增加"导出"按钮，并验证导出失败时的错误提示。

## 第 6 章 布局、通用组件与工具函数（6 课时）

- **实践任务**：修改 `navType`，比较三种导航模式的结构差异。

### 第 25 课：主题、设置面板与样式体系
- **学习目标**：理解主题切换与样式变量的实现原理。
- **知识点**：

### 第 26 课：通用业务组件（一）

### 第 27 课：通用业务组件（二）
- **学习目标**：掌握字典、富文本、图标选择、定时任务表达式等组件。
- **知识点**：
  - `DictTag`：`options`、`value`、`separator`，多值字典展示。
  - `Editor`：富文本编辑器（`@vueup/vue-quill`）的封装与内容存储。
  - `IconSelect`（`requireIcons.js`）：图标列表的加载方式。
  - `Crontab`：定时任务表达式的可视化生成（秒、分、时、日、月、周、年子组件）。
- **实践任务**：在一个表单中同时使用 `Editor` 和 `IconSelect`，保存并回显数据。

### 第 28 课：数据处理工具（一）：`utils/ruoyi.js`
- **学习目标**：熟练使用通用数据处理函数。
- **知识点**：
  - `parseTime`：日期格式化与格式字符串。
  - `addDateRange`：日期区间参数处理。
  - `handleTree`：扁平数据转树；`mergeRecursive`：对象递归合并。
  - `selectDictLabel` / `selectDictLabels`、`resetForm`、`sprintf`、`parseStrEmpty`、`getNormalPath`、`blobValidate`。
- **实践任务**：用 `handleTree` 把部门列表转换为树结构，并在树形选择器中展示。

### 第 29 课：数据处理工具（二）：字典、校验与安全
- **学习目标**：理解字典加载、表单校验规则和敏感数据处理。
- **知识点**：
  - `utils/dict.js` 的 `useDict` 与 Pinia 缓存的配合。
  - `utils/validate.js`：`validUsername`、`validEmail`、`validURL`、`isEmpty` 等规则。
  - `utils/passwordRule.js`：密码复杂度规则。
  - `utils/jsencrypt.js`：前端 RSA 加密登录密码的思路。
- **实践任务**：为一个表单添加密码复杂度校验与邮箱校验。

### 第 30 课：消息提示与弹窗统一封装
- **学习目标**：能使用统一的消息、通知、确认框和加载态。
- **知识点**：
  - `plugins/modal.js`：`msg*`、`alert*`、`notify*`、`confirm`、`prompt`、`loading`、`closeLoading`。
  - 为什么要统一封装：风格一致、便于替换底层组件库。
  - 结合 `request.js` 中的错误提示，理解不同层级的提示职责。
- **实践任务**：在删除操作中使用 `modal.confirm`，成功后用 `modal.msgSuccess` 提示。

### 第 33 课：部门、岗位与菜单管理

- **学习目标**：能从性能、安全和可维护性角度评估并改进代码。

  - 国际化与多语言的扩展思路（当前以中文为主）。
- **实践任务**：找出项目中一处可以做懒加载或拆分的代码，并给出改造方案与验证结果。

- **学习目标**：独立完成一个包含列表、新增、修改、删除、导入导出、字典、权限的完整模块。

- **项目建议**：图书管理、课程管理、资产管理、会议室预约等（任选其一）。
- **交付物**：

  3. 菜单与按钮权限配置说明；
  4. 字典配置清单；
  5. 一段 300–500 字的实现复盘（遇到的问题与解决思路）。
- **评分维度**：功能完整性、代码规范、权限与异常处理、可复用性、复盘质量。
